# Lion Acessórios

Site estático e responsivo com catálogo, busca, filtros, seleção do modelo do celular e carrinho persistente.

## Publicação

GitHub Pages: branch `main`, pasta `/ (root)`.

## Contato da loja

Configure `CONFIG.whatsappNumber` em `app.js` com DDI e DDD, somente números. Enquanto o número da loja não for informado, a lista abre o compartilhamento do WhatsApp para escolher um contato.

## Imagens

Logo fornecida pelo usuário, com fundo removido. Banner com aparência fotográfica gerado para esta atualização. Fotos individuais de produtos preservadas do arquivo original e associadas a cards distintos. Todos os valores permanecem sob consulta.
